# Как запустить игру в Телеграме

Игра — это обычный сайт. Телеграм открывает его внутри себя как мини-приложение.
Нужно три вещи: выложить сайт в интернет (GitHub Pages, бесплатно), создать бота
и привязать к нему сайт.

## 1. Выложить сайт на GitHub Pages

1. Зайди на github.com → **New repository**.
   - Название: `blackwood` (любое, оно попадёт в адрес).
   - **Public** (для бесплатного GitHub Pages репозиторий должен быть публичным).
   - Ничего не добавляй (без README, .gitignore, лицензии) — репозиторий должен быть пустым.
2. Код отправляет Claude (команды `git push`) — скажи ему адрес репозитория.
   В пустом репозитории ещё нет ветки `main`, поэтому самую первую версию
   придётся отправить прямо в `main` — Claude спросит на это разрешение.
   Все следующие изменения идут через ветку и pull request и попадают в `main`
   только после твоего «Merge».
3. После merge: **Settings → Pages → Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты появится адрес вида `https://ТВОЙ-ЛОГИН.github.io/blackwood/`.
   Открой его в браузере телефона и проверь, что игра запускается.

## 2. Создать бота

1. В Телеграме открой **@BotFather** → `/newbot`.
2. Имя бота (видят игроки): например, `Блэквуд-холл · детектив`.
3. Юзернейм (должен заканчиваться на `bot`): например, `blackwood_case_bot`.
4. BotFather пришлёт **токен**. Это пароль от бота: никому его не показывай,
   не вставляй в код и в чат с Claude. Для мини-приложения он не нужен.

## 3. Привязать игру к боту

### Мини-приложение с прямой ссылкой (рекомендую)

1. В @BotFather: `/newapp` → выбери своего бота.
2. Название: `Смерть в Блэквуд-холле`.
3. Описание: `Детектив на 20 минут. Одна ночь, пять подозреваемых, один убийца.`
4. Фото 640×360: отправь файл `docs/assets/botfather-cover.png`.
5. GIF — пропусти (`/empty`).
6. URL: адрес из шага 1.4.
7. Короткое имя (short name): например, `play`.
8. Получишь ссылку вида `https://t.me/blackwood_case_bot/play` — по ней игра
   открывается сразу, ей и делись с друзьями и в канале.

### Кнопка «Играть» в меню бота

`/mybots` → твой бот → **Bot Settings** → **Menu Button** → **Configure menu button**
→ отправь URL из шага 1.4 → название кнопки `Играть`.

## 4. Ссылка для кнопки «Поделиться»

Открой `js/config.js` и впиши ссылку из шага 3:

```js
export const SHARE_LINK = 'https://t.me/blackwood_case_bot/play';
```

Попроси Claude закоммитить это через pull request. Тогда игроки будут
делиться ссылкой, которая открывает игру прямо в Телеграме.

## 5. Пост в канал

Пример:

> Англия, 1926. Гроза, запертый особняк и мёртвый лорд в кабинете,
> закрытом изнутри. У вас одна ночь, чтобы назвать убийцу.
> Детектив на 20 минут прямо в Телеграме → https://t.me/blackwood_case_bot/play
> Напишите в комментариях свой ранг.

## Как обновлять игру

Любое изменение → Claude делает pull request → ты нажимаешь **Merge** →
через 1–2 минуты GitHub Pages обновляет сайт. Бота трогать не нужно.

## Если что-то не работает

- **Белый экран в Телеграме** — открой адрес сайта в обычном браузере.
  Если и там пусто, проверь, что Pages включён и смотрит на ветку `main`.
- **Старая версия после обновления** — закрой мини-приложение и открой снова
  (GitHub Pages держит кеш до 10 минут).
